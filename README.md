# Humanly Labs

Static site for Humanly Labs — content and interactive tools about
friendship, social anxiety, and social skills, plus three paid mini-courses.

Plain HTML/CSS/JS, no build step, deployed as a static site (Cloudflare
Pages-style `_headers` / `_redirects`).
